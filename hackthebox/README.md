# Hack The Box

Every machine I have taken from nothing to root (or Domain Admin), written up as
a client report. Newest first.

| Machine | OS | Solved | Chain |
|---|---|---|---|
| [Odori](odori/) | Linux | 26 Oct 2026 | A guest-readable backup share held the disk image used to rebuild the backup service, and the script inside it carried the SFTP password as a literal; that account's `ForceCommand` wrapper was writable by the account itself, and a root cron imported `helper` from a world-writable `__pycache__`, so a same-length bytecode edit plus a two-line `tar` left a setuid root shell |
| [Abducted](abducted/) | Linux | 26 Oct 2026 | Samba substituted the client-chosen print job name into `printaudit %J %s` unquoted (CVE-2026-4480), so a job named `\|sh` ran the spool body as `nobody`; a world-readable `rclone.conf` decoded to `scott`'s password; the `transfer` share's `force user` plus insecure wide links wrote `authorized_keys` into `/home/marcus`; `operators` could write the `smbd.service.d` drop-in and polkit let it restart the service, so an `ExecStartPre` line shipped setuid bash |
| [DevHub](devhub/) | Linux | 21 Oct 2026 | MCPJam Inspector 1.4.2 executed any command posted to its unauthenticated `/api/mcp/connect` (CVE-2026-23744); the Jupyter token sat in the process list and opened a terminal as `analyst`; a root-run ops service, owned by that account, carried a hidden `ops._admin_dump` tool that returned root's private SSH key |
| [Principal](principal/) | Linux | 21 Oct 2026 | pac4j-jwt 6.0.3 accepted an unsigned `PlainJWT` inside a JWE the server would open with a key it published; the dashboard showed a deployment password that opened an SSH account; that account could read the SSH CA private key, and `TrustedUserCAKeys` with no principals file let a certificate be minted for `root` |
| [Fireflow](fireflow/) | Linux | 19 Oct 2026 | The public "Open Agent" button leaked a Langflow `flow_id`; CVE-2026-33017 gave code execution as the web account; a password reused from Langflow's config opened `nightfall`; that account held credentials for an MCP server with a JWT flaw, and kubelet `nodes/proxy` finished the job as root on the node |
| [Reactor](reactor/) | Linux | 11 Oct 2026 | A Node.js application on TCP 3000 running framework versions below the fixed release for a published flaw: one crafted request, no account needed. Its own secrets followed — the user database and an internal API key — then a staff password reused for SSH, then the machine's top privilege |
| [WingData](wingdata/) | Linux | 5 Jul 2026 | Virtual host routing exposed an internal FTP web client (Wing FTP Server 7.4.3) with an unauthenticated RCE; a salted hash in a user config cracked offline and reused for SSH; a `sudo` backup-restore script plus `tarfile` wrote as root |
| [Nexus](nexus/) | Linux | 2 Jul 2026 | A password left in a public Gitea repository's history opened Krayin CRM, which had an unauthenticated file-upload RCE (CVE-2026-38526); the CRM config held `jones`' SSH credentials; a root-owned Gitea template-sync service joined attacker input with an unsanitised `os.path.join()` and wrote into `/root/.ssh/authorized_keys` |
| [Orion](orion/) | Linux | 28 Jun 2026 | CraftCMS with a no-login RCE, exploited for a foothold; database credentials in the config, a weak password reused for SSH, and a local telnet service with an authentication bypass for root |
| [VariaType](variaType/) | Linux | 16 Jun 2026 | An exposed `.git` directory with hardcoded credentials; an LFI via path-traversal filter bypass; CVE-2025-66034 (fonttools arbitrary write), CVE-2024-25082 (fontforge command injection), and CVE-2025-47273 (setuptools path traversal through `sudo`) ending in an SSH key for root |
| [Facts](facts/) | Linux | 19 Apr 2026 | Anonymous access to the `randomfacts` MinIO bucket; a Camaleon CMS 2.9.0 path-traversal LFI (CVE-2024-46987); mass assignment to admin (CVE-2025-2304); S3 keys in the CMS settings opened an internal bucket with `trivia`'s encrypted SSH key; `sudo facter` with `FACTORLIB` blocked, bypassed by `--custom-dir` |
| [CCTV](cctv/) | Linux | 9 Apr 2026 | ZoneMinder 1.37.63 with default admin credentials; CVE-2024-51482 SQL injection pulled bcrypt hashes and `mark`'s cracked; a motionEye instance on localhost, running as root, was reachable by port forward and RCE-able (CVE-2025-60787) |
| [Support](support/) | Windows | 8 Apr 2026 | Anonymous SMB to a non-default share; hardcoded encrypted credentials in a .NET binary; a plaintext password in an LDAP attribute; `GenericAll` on the Domain Controller object turned into RBCD and Domain Admin |
| [TwoMillion](TwoMillion/) | Linux | 5 Apr 2026 | An invite-code check bypassed through an obfuscated script; broken access control in the API let a low-privilege account promote itself to admin; OS command injection in the admin console gave a shell as `www-data`; `.env` credentials, then CVE-2023-0386 for root |
| [Cap](cap/) | Linux | 4 Apr 2026 | Unauthenticated IDOR exposed packet captures, one of which carried plaintext FTP credentials; those were reused for SSH; a Linux capability on the Python 3.8 binary (`cap_setuid`) turned into root |
| [Expressway](expressway/) | Linux | 10 Dec 2025 | An IKEv1/XAUTH VPN on UDP 500 with a weak pre-shared key, cracked offline; the XAUTH credentials opened SSH as `ike`; `sudo` 1.9.17 was vulnerable to CVE-2025-32463, NSS library injection through `-R`, for root |
| [Soulmate](soulmate/) | Linux | 10 Oct 2025 | A hidden virtual host running CrushFTP 11.W.657, vulnerable to CVE-2025-31161 (unauthenticated admin creation); a PHP web shell, then plaintext credentials in an Erlang startup script for `ben`; a misconfigured Erlang SSH daemon on localhost, running as root |
